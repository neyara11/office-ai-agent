## Обзор

Office AI Агент — это AI Native плагин для Office, разработанный на **Visual Studio Community 2022/2026 + Visual Basic.NET + VSTO + WebView2**. Он добавляет в Excel, Word и PowerPoint чат-панель, чтение контекста документа, умное форматирование и вычитку, анализ данных, генерацию контента и расширения MCP/Skills, позволяя управлять текущим открытым файлом Office на естественном языке.

### 🎯 Цели проекта

- **Умная автоматизация офисных задач**: AI-помощник для повседневной работы
- **Кроссплатформенность**: совместимость с Microsoft Office и WPS
- **Дружелюбный интерфейс**: простые и наглядные сценарии
- **Постоянное развитие**: регулярные обновления и новые возможности

## Возможности

### ✨ Ключевые возможности

- **AI Native Chat**: запросы прямо к текущему документу, выделению, таблице или слайду в правой панели Office.
- **Умное форматирование Word**: форматирование на естественном языке, перестройка заголовков и нумерации, автонумерация, единые стили, предпросмотр и обратная связь по выполнению.
- **Вычитка и рецензирование Word**: замечания по опечаткам, пунктуации, стилистике и официальной речи без навязчивых всплывающих подсказок.
- **Анализ данных Excel**: чтение контекста выделения и листа, вопросы по данным, обработка и анализ, помощь с формулами и диаграммами.
- **Работа с PowerPoint**: создание презентаций, продолжение текста, перевод, оформление и рецензирование.
- **AI-перевод**: перевод абзацев, страниц и документов на разные языки с выбором модели.
- **Память и контекст**: краткосрочный контекст сессии, долговременная память и контекст текущего файла Office.
- **Расширения MCP / Skills**: встроенный MCP Client для подключения MCP Server и Skills, расширяющих внешние инструменты.
- **Agent Loop**: для сложных задач используется цепочка plan -> act -> observe -> repair -> explain, а не просто генерация ответа.
- **Несколько моделей**: поддержка DeepSeek, Doubao и других моделей с расширяемой конфигурацией.

## Архитектура AI Native

Проект развивается от «чат-плагина» к «исполняемому Office Agent». Цель — чтобы AI мог наблюдать текущий файл Office, планировать действия, вызывать инструменты, проверять результат и автоматически исправлять ошибки.

#### 🎯 Ключевые способности

| Способность | Статус | Описание |
|------|------|------|
| **Harness** | В развитии | Превращает операции Office в вызываемые, наблюдаемые и проверяемые способности для AI |
| **Agent Loop** | В развитии | Сложные задачи проходят планирование, выполнение, наблюдение, исправление и объяснение |
| **Контекст** | Подключено | Автоматически читает выделение, весь текст, абзацы, стили, таблицы и контекст сессии |
| **Word Action Harness** | Подключено | Входные точки для форматирования, вычитки и автонумерации Word на естественном языке |
| **MCP Client** | Подключено | Подключение MCP Server для расширения инструментов |
| **Система памяти** | Подключено | Поиск по недавним сессиям и долговременной памяти |
| **Предпросмотр/Отмена** | В развитии | Для важных операций записи приоритет у предпросмотра, объяснения и отката |

#### ✨ Целевой пользовательский опыт

**1. Возможности Word: от чата к выполнению**

```text
Пользователь: "Замени нумерацию выше на 12345"
  ↓
Harness читает абзацы, нумерацию и диапазоны текущего документа Word
  ↓
Numbering Agent планирует и выполняет исправление автонумерации
  ↓
Observer проверяет непрерывность нумерации и возвращает результат
```

**2. Плагин сам читает контекст**

```text
Пользователь выделил несколько абзацев в Word
Пользователь: "Перестрой нумерацию и заголовки"

AI не должен переспрашивать про текст, выделение и формат нумерации,
а сначала читает выделение и структуру абзацев и предлагает план или предпросмотр.
```

**3. Понимание данных Excel**

```text
Пользователь выделил A1:B100 с данными о продажах
AI автоматически знает:
- Выделение: A1:B100
- Тип данных: таблица (с заголовками)
- Колонки: продавец, сумма продаж
- Превью первых 3 строк

Пользователь: "Посчитай комиссию"
AI: понимает, что считать нужно в колонке B, и не переспрашивает
```

#### 🔍 Технические особенности

- **Атомарные инструменты Harness**: операции Office вроде `ListParagraphs`, `GetParagraphInfo`, `SetParagraphFormat` доступны как комбинируемые способности.
- **Planner / Agent**: строит структурированный план под цель пользователя, а не превращает естественный язык сразу в ответ чата.
- **Observer / Repair**: после выполнения читает реальное состояние Office и исправляет план по результатам наблюдения.
- **Capability / Skill**: новые способности подключаются как обнаруживаемые, объяснимые и тестируемые единицы.

## Установка

### Системные требования

- **ОС**: Windows 10/11
- **Офисный пакет**: Microsoft Office 2016+ или WPS Office
- **Среда выполнения**: .NET Framework 4.7.2+, Microsoft Edge WebView2 Runtime, VSTO Runtime
- **Среда разработки**: Visual Studio Community 2022/2026 + рабочая нагрузка VSTO
- **Сборка установщика**: для `OfficeAgent/OfficeAgent.vdproj` в текущем экземпляре Visual Studio должно быть установлено расширение `Microsoft Visual Studio Installer Projects`

### Установка для пользователя

1. Закройте работающие Word, Excel, PowerPoint и WPS.
2. Скачайте `OfficeAgent.msi` с сайта или со страницы релизов.
3. Запустите установщик; если корпоративные политики ограничивают запись в реестр плагинов Office, запустите от имени администратора.
4. После установки откройте Word, Excel или PowerPoint.
5. Найдите на ленте вход в AI-помощник и при первом использовании настройте модель, API Key, MCP/Skills и другие параметры.
6. Если Office отключил надстройку, включите её в `Файл -> Параметры -> Надстройки`.

### 📦 Загрузка установщика

- **Официальная загрузка**: [https://www.officeso.cn/](https://www.officeso.cn/)
- **Последняя версия**: актуальный стабильный релиз
- **Простая установка**: установщик для Windows в один клик

### Сборка и отладка из исходного кода

```bash
# Восстановление зависимостей
msbuild AiHelper.sln -t:Restore

# Рекомендуется: собрать только четыре кодовых проекта (без установщика vdproj)
.\build-code.bat
# или
powershell -File .\scripts\build-code-projects.ps1 -Configuration Debug

# Подготовка перед сборкой MSI (Release-код + аудит SourcePath, MSI не создаётся)
.\build-installer-prep.bat
```

**Не** используйте полный Debug Rebuild решения для проверки компиляции кода: `SourcePath` в `OfficeAgent.vdproj` указывает на `bin\Release`, поэтому сбой проекта установщика часто ошибочно принимают за ошибку компиляции. Подробнее см. [Ошибка открытия OfficeAgent.vdproj в Visual Studio 2026](docs/VS2026-InstallerProjects.md).

Для отладки VSTO-плагина рекомендуется запускать соответствующий процесс Office из Visual Studio. Debug-сборка обычно используется для отладки; для распространения рекомендуется Release-сборка и установка через MSI.

### Visual Studio 2026 не открывает OfficeAgent.vdproj

Если VS 2026 сообщает о несовместимости `OfficeAgent.vdproj` и выводит `54435603-dbb4-11d2-8724-00a0c9a8b90c`, причина обычно не в старой версии VB.NET, а в отсутствии поддержки типа проектов `.vdproj` в текущем экземпляре VS.

Порядок действий:

1. Установите и включите расширение [Microsoft Visual Studio Installer Projects](https://marketplace.visualstudio.com/items?itemName=VisualStudioClient.MicrosoftVisualStudio2022InstallerProjects) в VS 2026.
2. Перезапустите Visual Studio и снова откройте `AiHelper.sln`.
3. Если расширение временно недоступно, можно собирать и отлаживать `ShareRibbon`, `WordAi`, `ExcelAi`, `PowerPointAi`, а MSI собирать в экземпляре Visual Studio с этим расширением.
4. Подробнее см. [Ошибка открытия OfficeAgent.vdproj в Visual Studio 2026](docs/VS2026-InstallerProjects.md).

### Предупреждение о цифровой подписи Excel XLL

В Debug-среде `ExcelAi-AddIn64.xll` может сообщать об отсутствии цифровой подписи. На этапе разработки это решается через доверенные расположения Office, включение надстройки или внутренний путь установки; для публичного распространения стоит предусмотреть подпись кода. Отсутствие платного сертификата не мешает локальной разработке и проверке функций.

### Сертификаты разработки VSTO и подпись релиза

- **Разработка**: каждый плагин подписывает манифест VSTO локальным `*_TemporaryKey.pfx`. Если после клонирования подпись не проходит, выполните:
  `powershell -File .\scripts\ensure-vsto-temp-keys.ps1`
- **Запрещено** коммитить `*.pfx` / `*.snk` и приватные ключи релизной подписи в Git.
- **Релиз**: используйте `build/SignArtifacts.ps1` и переменные окружения `OFFICE_AI_SIGN_CERT_THUMBPRINT` или `OFFICE_AI_SIGN_PFX`; не подписывайте публичный MSI ключом TemporaryKey.
- Подробнее см. `docs/signing-and-certificates.md`.

## Использование

### Быстрый старт

1. **Запустите Office**: откройте Excel, Word или PowerPoint
2. **Откройте AI-помощника**: найдите вкладку AI на ленте
3. **Настройте модель**: укажите API Key, адрес модели и параметры
4. **Добавьте контекст**: выделите текст, диапазон или слайд и введите запрос
5. **Выполните задачу**: AI проанализирует, сгенерирует, оформит, проверит или объяснит результат по контексту файла

### Типичные запросы в Word

- `Перестрой нумерацию и заголовки`
- `Замени нумерацию выше на 12345`
- `Увеличь шрифт всего текста на 2 пункта`
- `Проверь весь текст, исправь только явные опечатки и пунктуацию`
- `Приведи выделенный фрагмент к стилю официального отчёта`

### Типичные запросы в Excel

- `Проанализируй аномалии в выделенном диапазоне`
- `Составь бизнес-анализ по этой таблице`
- `Построй диаграмму, подходящую для этих данных`
- `Добавь формулу в этот столбец и объясни её`

### Типичные запросы в PowerPoint

- `Создай итоговый слайд по текущей теме`
- `Улучши формулировки на выделенном слайде`
- `Сделай эту страницу в стиле делового доклада`
- `Проверь всю презентацию на опечатки и стилистику`

### Расширенные возможности

- **MCP/Skills**: подключение внешних инструментов, баз знаний и корпоративных систем.
- **Память**: учёт недавних сессий и долговременной памяти, чтобы не объяснять одно и то же заново.
- **Объяснение выполнения**: для важных операций записи показывается, что будет изменено, что уже изменено и где нужно подтверждение.
- **Предпросмотр**: форматирование и вычитка с высоким влиянием сначала проходят через предпросмотр и обратную связь по выполнению.
