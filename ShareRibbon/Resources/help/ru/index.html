Справка Office AI Agent

Локальная справка для работы в закрытом контуре — без обращения к внешним сайтам.

Выберите приложение, с которым работаете:

WordДокументы, продолжение текста, вычитка, форматирование ExcelФормулы, диаграммы, анализ данных, пакетная генерация PowerPointПрезентации, макеты, заметки докладчика

С чего начать

  1. Откройте вкладку AI-ассистент на ленте приложения.
  2. Нажмите Настройка API и укажите адрес, ключ и модель вашего внутреннего сервера.
  3. Если сервер использует самоподписанный сертификат, включите для провайдера доверие к нему.
  4. Откройте AI-чат и задайте вопрос обычными словами — например «отформатируй документ по ГОСТ».
Это локальная краткая справка. Полная версия справки переводится отдельно; до её готовности кнопка «Документация» открывает этот файл, а не внешний сайт.
