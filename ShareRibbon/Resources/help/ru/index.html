Справка Office AI Agent

Локальная справка для работы в закрытом контуре — без обращения к внешним сайтам.

Выберите приложение, с которым работаете:

WordПродолжение текста, вычитка, форматирование, перевод ExcelАнализ данных, диаграммы, пакетная генерация, функции AI PowerPointСоздание презентаций, перевод, заметки докладчика ВопросыНастройка API, сертификаты, кэш, типовые проблемы

Быстрый старт

  1. Установите надстройку и перезапустите Office. На ленте появится вкладка AI-ассистент.
  2. Нажмите Настройка API и укажите адрес вашего OpenAI-совместимого сервера, ключ и модель. Адрес можно давать как базовый (https://host/v1) — путь до /chat/completions добавляется сам.
  3. Если сервер отдаётся по HTTPS с самоподписанным сертификатом, включите для этого провайдера флаг «Разрешить самоподписанный сертификат (небезопасно)».
  4. Откройте AI-чат и опишите задачу обычными словами — например «отформатируй документ по ГОСТ».
Вкладка и кнопки называются одинаково во всех приложениях, но часть кнопок показывается только там, где соответствующий сценарий имеет смысл. Полный список кнопок для каждого приложения — на страницах Word, Excel и PowerPoint.

Требования

  • Windows 10 или новее.
  • Office 2016+ (Word, Excel, PowerPoint) или WPS 2019+.
  • .NET Framework 4.7.2, VSTO Runtime, WebView2 Runtime — ставятся офлайн-установщиком.
  • Настроенный провайдер модели: внутренний OpenAI-совместимый endpoint или локальная модель.

Что входит в интерфейс

Вкладка AI-ассистент содержит группы:

  • Настройка моделей — «Настройка API» и «Промпты».
  • AI-диалог — «AI-чат» и «AI-перевод».
  • AI-обработка текста — «Продолжить», «Вычитка», «Форматирование».
  • Инструменты — «Анализ данных», «Захват страниц», «Подсветка», «Пакетная генерация».
  • Подключение MCP — подключение внешних MCP-инструментов.
  • О программе и настройки — «О программе» и «Очистить кэш».
  • Справка и обучение — Документация, открывает эту локальную справку.

Основные понятия

ТерминЗначение
ПровайдерНастроенное подключение к модели: адрес, ключ, модель, флаги безопасности.
ПромптСистемная инструкция, задающая роль и стиль ответов. Настраивается кнопкой «Промпты».
MCPПротокол подключения внешних инструментов (Model Context Protocol).
КэшКаталог с настройками, историей чатов и служебными данными. Очищается одноимённой кнопкой.

Работа в закрытом контуре

  • Все запросы идут только на настроенный вами endpoint — внешние сервисы не используются.
  • Кнопки бесплатных облачных сервисов в этой сборке скрыты.
  • Справка открывается из локального файла, интернет для неё не нужен.
  • «Захват страниц» требует сети и является необязательным: без сети он показывает сообщение и не мешает остальным функциям.
  • Ключи и настройки хранятся локально в профиле пользователя.
