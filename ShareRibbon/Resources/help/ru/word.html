Сценарии

Продолжение текста

  1. Поставьте курсор в конец фрагмента, который нужно продолжить.
  2. Нажмите Продолжить. Текст допишется с учётом контекста.
  3. Если результат не тот, уточните задачу в «AI-чате»: «сократи», «сделай официальнее», «добавь выводы».

Вычитка

  1. Выделите фрагмент или перейдите к началу документа для проверки целиком.
  2. Нажмите Вычитка и дождитесь списка замечаний.
  3. Примите или отклоните правки; спорные места можно переформулировать через чат.

Форматирование по стандарту

  1. Нажмите Форматирование.
  2. Ассистент определит тип документа и применит подходящий стандарт оформления.
  3. Дополнительные требования задавайте в чате: «шрифт Times New Roman 14», «интервал 1,5», «заголовки полужирным».

Перевод

  • Выделение — переводится только выделенный фрагмент.
  • Документ — переводится весь текст, оформление по возможности сохраняется.
  • Иммерсивный режим — перевод показывается рядом с оригиналом для вычитки.

Захват веб-страницы

Открывает страницу по ссылке и переносит её содержимое в документ. Требует доступа в сеть и не входит в обязательный offline-сценарий.

Примеры команд

  • «Отформатируй документ по ГОСТ, шрифт Times New Roman 14»
  • «Пронумеруй заголовки и собери оглавление»
  • «Проверь орфографию и пунктуацию в выделенном фрагменте»
  • «Продолжи текст в деловом стиле»
  • «Переведи документ на английский, форматирование сохрани»
  • «Сократи выделение на треть, смысл сохрани»
  • «Сделай заголовки полужирными, а подзаголовки — курсивом»

Полезно знать

  • Перед крупными изменениями сохраните документ — часть операций откатывается через Ctrl+Z.
  • Если результат не тот, опишите правку в диалоге, а не повторяйте команду вслепую.
  • Для работы нужен настроенный провайдер: Настройка API → адрес, ключ, модель.
