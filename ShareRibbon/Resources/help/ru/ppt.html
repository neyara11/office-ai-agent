Возможности AI-ассистента в презентациях.

Основные действия на ленте

КнопкаЧто делает
AI-чатДиалог с AI и выполнение операций над слайдами и фигурами.
ПродолжитьДополняет содержимое слайда с учётом контекста.
AI-переводПереводит текст слайдов, сохраняя структуру.

Примеры команд

  • «Создай презентацию из 8 слайдов о результатах квартала»
  • «Сделай титульный слайд и слайд с ключевыми показателями»
  • «Приведи оформление всех слайдов к единому стилю»
  • «Добавь заметки докладчика к каждому слайду»

Полезно знать

  • Профессиональная вёрстка выполняется по структурированному описанию слайдов; при неудаче изменения откатываются.
  • Откат доступен через Ctrl+Z; иногда может понадобиться несколько нажатий.
  • Для работы нужен настроенный провайдер: Настройка API → адрес, ключ, модель.
