Сценарии

Анализ данных

  1. Выделите диапазон с данными или откройте нужный лист.
  2. Нажмите Анализ данных и при необходимости добавьте уточнение в чате («по месяцам», «только за 2025 год»).
  3. Ассистент построит результат на листе: сводки, формулы, диаграммы или отчёт.
  4. Проверьте результат и при необходимости попросите исправить: «поменяй тип диаграммы на линейную».

Диаграммы

  • Диаграмма строится по выделенным данным; ассистент сам подбирает подходящий тип.
  • Если данные содержат объединённые ячейки или смешанные типы, сначала приведите их к табличному виду.
  • Уточнить оформление можно словами: «подпиши оси», «добавь легенду справа», «сделай накопительную диаграмму».

Пакетная генерация

  1. Нажмите Пакетная генерация.
  2. Опишите поля будущей таблицы и укажите количество строк.
  3. Подтвердите — данные будут записаны на активный лист, начиная со строки заголовков.

Подсветка строки и столбца

  • Одиночный клик по кнопке включает и выключает режим подсветки.
  • Двойной клик открывает диалог выбора цвета подсветки.

Функция ALLM

В формулах доступна функция ALLM — вызов модели прямо из ячейки:

ALLM(промпт; [модель]; [системный_промпт]; [температура]; [макс._токенов])

  • промпт — вопрос или инструкция (обязательно).
  • модель — имя модели; пусто — модель по умолчанию из настроек.
  • температура — 0.0–1.0, по умолчанию 0.7.
  • макс._токенов — ограничение длины ответа, по умолчанию 1000.

Пример: =ALLM("Кратко опиши этот регион"; ; "Отвечай по-русски")

Примеры команд

  • «Проанализируй выделенные данные и построй диаграмму по месяцам»
  • «Добавь столбец с формулой: цена × количество»
  • «Удали дубликаты и отсортируй по убыванию суммы»
  • «Сделай сводную таблицу по регионам и категориям»
  • «Найди выбросы в продажах и выдели их»
  • «Посчитай итоги по кварталам и добавь строку "Итого"»

Полезно знать

  • Формулы можно вводить как задачу: «в C2 посчитай сумму A2:B2».
  • Перед массовыми изменениями сохраните книгу — откат доступен через Ctrl+Z.
  • Если после команды данные выглядят неверно, откатитесь через Ctrl+Z и уточните формулировку.
  • Для работы нужен настроенный провайдер: Настройка API → адрес, ключ, модель.
